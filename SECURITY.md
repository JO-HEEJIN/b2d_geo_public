# Security policy

Please do not open a public issue for a suspected vulnerability, exposed secret, or privacy concern.

Report it privately to **info@birth2death.com** with:

- the affected route, file, or revision;
- a minimal reproduction;
- the likely impact; and
- any suggested mitigation.

Do not include live API keys, credentials, personal data, or raw licensed data in the report. Acknowledgement and remediation timing depend on severity and reproducibility.

## Supported version

The `main` branch is the only supported public snapshot. The live service may run a newer private revision.
