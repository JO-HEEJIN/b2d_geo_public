# 소상공인 상가(상권)정보 데이터 명세

## 데이터셋 개요

- **데이터셋 ID**: 15083033
- **기준 분기**: 20260331 (2026년 1분기)
- **갱신 주기**: 분기별
- **차기 등록 예정일**: 2026-08-01
- **원천**: 국세청 / 카드사 데이터 기반
- **이용 조건**: 무료, 로그인 불필요, 이용 제한 없음

## 다운로드 절차

전국 데이터가 단일 ZIP 파일(약 341MB)로 제공되며, ZIP 내부에 시도별 CSV 17개와
열람 방법 안내 텍스트가 들어 있다.

1. `https://www.data.go.kr/data/15083033/fileData.do` 페이지 HTML을 가져온다.
   User-Agent에 `Mozilla/5.0`을 지정한다.
2. 페이지 HTML에서 `atchFileId`와 `fileDetailSn` 값을 파싱한다.
   - **주의: `atchFileId`는 분기마다 갱신된다. 코드에 하드코딩하지 말고 매번
     페이지에서 파싱할 것.** (2026-03-31 기준 값은 `FILE_000000003632420`,
     `fileDetailSn=1` 이었다.)
3. 다운로드 URL 패턴:
   `https://www.data.go.kr/cmm/cmm/fileDownload.do?atchFileId={atchFileId}&fileDetailSn={fileDetailSn}`
   - 요청 시 User-Agent(`Mozilla/5.0`)와 Referer(`https://www.data.go.kr/data/15083033/fileData.do`)
     헤더가 필요하다. 헤더가 있으면 HTTP 200으로 응답한다.
   - 응답: `Content-Disposition: attachment; filename="소상공인시장진흥공단_상가(상권)정보_20260331.zip"`,
     `Content-Length: 341021001`.
4. ZIP 내부 파일명은 UTF-8로 인코딩되어 있다 (ZIP general purpose flag bit 0x800 = set).
   - 시도별 CSV 17개: 강원, 경기, 경남, 경북, 광주, 대구, 대전, 부산, 서울, 세종,
     울산, 인천, 전남, 전북, 제주, 충남, 충북.
   - 파일명 예시: `소상공인시장진흥공단_상가(상권)정보_세종_202603.csv`
   - 크기: 세종 약 9.6MB(최소), 경기 약 368MB(최대), 서울 약 293MB.
   - 그 외 `[필독]파일열람방법.txt` (열람 방법 안내) 포함.

## 인코딩 / 구분자

- **인코딩**: UTF-8 (BOM 없음). `file` 명령 판정 결과 `CSV text`.
- **구분자**: 쉼표(`,`).

동봉된 `[필독]파일열람방법.txt` 원문 인용:

> 기존 euc-kr 데이터 추출형식으로 인해 업소명 오류가 발견되었으며 이를 개선하고자
> UTF-8 형식으로 추출하였습니다.
>
> UTF-8의 코드 페이지 넘버는 65001입니다.
>
> 구분 기호는 '쉼표' 선택합니다. (기본이 쉼표로 선택되어 있음)

## 좌표계

- **결론: EPSG:4326 (WGS84 경위도)**로 판단한다.
- **근거는 실측이다. 공식 문서(data.go.kr 페이지, API 문서, 동봉 readme)에는
  좌표계 또는 EPSG 코드에 대한 명시적 기술이 없다.** 이 점을 명확히 기록해 둔다.
- 실측 검증 내용:
  - 경도/위도 값이 투영되지 않은 십진도(decimal degrees)이며 소수점 11~13자리.
  - 경도(경도 컬럼)가 앞, 위도가 뒤 순서.
  - 세종 CSV 상위 2,000행의 bbox 검증: 경도 127.15~127.41, 위도 36.42~36.73.
    전 행이 한반도 bbox(경도 124~132E, 위도 33~39N) 내부에 위치.
  - 중부원점 TM 등 투영 좌표계 값이 아님.
- 적재 시 좌표계 상수는 코드에 값을 박되, "실측 근거로 확정, 공식 명세에는 미기재"
  라는 취지의 주석을 반드시 함께 남긴다. 좌표 변환이 필요하면 PostGIS
  `ST_Transform`만 사용한다.

## 데이터 품질 주의사항

- **주소 컬럼 시도명 중복 버그**: 지번주소/도로명/도로명주소 컬럼에서 시도명이
  두 번 반복되는 경우가 있다. 주소 파서에서 처리 필요.
  - 예시(지번주소): `세종특별자치시 세종특별자치시 조치원읍 원리 101-1`
  - 예시(도로명주소): `세종특별자치시 세종특별자치시 조치원읍 조치원8길 16`
- **시도/시군구명 동일 케이스**: 세종특별자치시처럼 시도명과 시군구명이 같은 값을
  가지는 광역시/특별자치시가 존재한다.
- **nullable 컬럼**: 지점명, 건물명, 동정보, 층정보, 호정보, 지번부번지,
  건물부번지 등은 빈값이 흔하다.
