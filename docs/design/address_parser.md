# 한국 주소 파서 설계 (Phase 2-1)

작성 2026-07-08 (야간 자율 세션). 목표: 자유 입력 한국 주소 문자열을
구조화(Parsed)해 3단 폴백 매칭(정확→정규화→trigram)의 1·2단 키를 만든다.
원칙: 파서는 **해석만** 하고 추측 보정하지 않는다 — 모호하면 모호하다고
표시하고 폴백 단계로 넘긴다.

## 1. 출력 구조

```go
type Parsed struct {
    Sido     string // 정규화된 시도 ("서울특별시")
    Sigungu  string // 시군구 ("중구", "성남시 분당구"처럼 2어절 가능)
    Emd      string // 읍면동리 (신주소면 빈값 가능)
    Road     string // 도로명 (신주소)
    Under    bool   // 지하 여부
    BldNo    string // 건물번호 "110" 또는 "110-2"
    Jibun    string // 지번 "179-3" (구주소)
    San      bool   // 산 지번
    Extra    string // 괄호 병기 등 참고 잔여 ("(태평로1가)")
    Kind     Kind   // Road | Jibun | Ambiguous
    Warnings []string
}
```

## 2. 토크나이저

- 공백 분리 전에 전처리: 전각→반각, 쉼표/마침표 제거, 괄호 블록 추출해
  Extra로 격리 (예: "세종대로 110 (태평로1가)" → Extra="(태평로1가)").
- "산79-3"처럼 붙은 산 접두는 "산" + "79-3"으로 분리.
- "110번지", "110번길"의 "번지" 제거는 지번 문맥에서만 (도로명 "~번길"은 보존).

## 3. 상태기계

상태: S0(시작) → SIDO → SIGUNGU → {EMD | ROAD} → NUM → END.
각 토큰을 순서대로 소비하며 전이. 핵심 판정 규칙:

1. **시도 인식**: 17개 시도 전칭 + 축약 사전 매핑
   ("서울"→"서울특별시", "전북"→"전북특별자치도", "강원"→"강원특별자치도" —
   2024년 특별자치도 개편 반영. 사전은 admin_areas에서 생성해 하드코딩 최소화).
   시도 생략 입력 허용: S0에서 시군구 패턴 만나면 Sido="" + Warning.
2. **시군구**: "~시/군/구" 접미. "성남시 분당구"류 2단은 연속 소비.
   광역시 산하 군("부산 기장군") 처리 동일.
3. **도로명 vs 동 판정** (최대 난제):
   - "~로/길" 접미 → ROAD 확정. 단 "~가로/골목길" 등 변형 포함, "종로"처럼
     로로 끝나는 2글자 도로명 주의 — "종로 1" (도로명) vs "종로1가" (법정동).
   - "~동/읍/면/리/가" 접미 → EMD. **"1동/일동" 변형**: "성수동1가",
     "성수1동"(행정동), "일원동" 구분 — 행정동 숫자 접미("~1동")는 법정동
     변환 없이 Warning 부착 (매칭 단계에서 법정동 사전과 대조).
   - 판정 불가 토큰은 Kind=Ambiguous로 두고 두 경로 모두 매칭 시도.
4. **숫자부**:
   - ROAD 문맥: "110", "110-2", "지하110" → BldNo/Under.
   - EMD 문맥: "179-3", "산79" → Jibun/San.
   - 둘 다 아닌 문맥(시군구 직후 숫자)은 Ambiguous.
5. **잔여 토큰**: 건물명/동호수 추정분은 Extra로 — 버리지 않되 매칭 키에서 제외.

## 4. 매칭 키 생성

- 1단(정확): `Sido Sigungu Road [지하 ]BldNo` 어절 단일 공백 결합 —
  **buildings.norm_road 관례와 동일** (internal/etl/entrance.Norm 참조).
- 시도 생략 시: 시군구+도로명으로 조회 후 복수 시도 히트면 후보 목록 반환
  (단정 금지).
- 2단(정규화): 축약 시도 복원, "번지" 제거, 행정동→법정동 사전 치환 후 재시도.
- 3단(trigram): norm_road/norm_jibun trgm 유사도, score = similarity 그대로
  노출 (가공 점수 금지 — 사실 반환 원칙과 일관).
